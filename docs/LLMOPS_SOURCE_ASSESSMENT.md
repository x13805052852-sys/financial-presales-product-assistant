## 首版产品与组件边界

| 产品域 | 当前中文名称 | 主要职责 | 首版关键组件 |
| --- | --- | --- | --- |
| Corpus Studio | 星解 | 多模态语料开发与管理 | 语料处理、增强、标注、评测 |
| Model Foundry | 星铸 | 模型训练、推理和算力运营 | 模型生命周期、模型评测、TokenFactory |
| Knowledge Lodge | 星典 | 知识工程与推理 | KB Agent、多索引、业务本体、KnowledgeBase |
| Agent Go | 星将 | 智能体和应用开发及运营 | AgentBox、Agent Buddy、Agent Session Manager |
| AI Infra | 无固定中文简称 | 企业级 AI 基础设施与统一治理 | Catalog、Discover、空间、身份、权限、审计、观测 |

关键口径：

- TokenFactory 属于 Model Foundry 的统一模型服务能力，不作为与五个产品域平级的第六个产品。
- AgentBox 是构建网页应用和 Agent Buddy 的工作台；Agent Buddy 是交付给业务使用的数字员工。
- Agent Session Manager 负责跨 Agent、跨渠道的会话控制、审计、Memory 与反馈闭环。
- Catalog 偏资产登记和治理，Discover 偏资产发现和消费。
- 旧材料曾使用 Agent Go“星构”，当前 3.0 核心资料使用“星将”；机器人需要识别旧称，但回答应采用当前名称并提示版本差异。

## 资料优先级和冲突处理

证据优先级从高到低：

1. 经产品负责人确认的当前发布说明和售卖口径。
2. 本次 5 份 LLMOps 3.0 当前版材料。
3. 明确标注版本的架构图和使用手册。
4. 历史培训、历史案例和旧版手册。
5. 测试报告、漏洞扫描和竞品材料只在专项举证时使用。

发生以下情况不得静默合并：

- 同一组件在新旧资料中的中文名称或归属不同；
- 旧版手册描述了当前资料未确认的功能；
- 页面标注规划中、路线图或未来版本；
- 性能数字缺少完整测试环境；
- 竞品或市场统计缺少当前可核验来源。

机器人应返回已确认部分，并追加“口径待产品专家确认”或“当前资料不足”，不能由模型自行补齐。
