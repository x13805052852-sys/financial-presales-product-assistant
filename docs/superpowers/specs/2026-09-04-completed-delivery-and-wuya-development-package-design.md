## 2. 已完成成果包

### 2.1 纳入范围

- 应用代码与配置样例：`src/`、`package.json`、锁文件、TypeScript 配置和 `.env.example`。
- 自动测试：TypeScript 测试、Python 仓库检查及必要测试配置。

### 2.2 排除范围

- `.env`、API Key、BotID、Bot Secret 和其他真实凭证。
- `logs/`、`node_modules/`、`dist/`、`work/`、缓存、预览图和检查中间文件。

## 3. 无涯知识库开发清单

首版覆盖三条产品线，但分别建立产品边界：

- 无涯问知 / TKH
- 无涯问数 / Logits
- Co-Worker / XClaw

部署手册、历史版本、测试报告、专利、视频和演示素材按条件资料或独立证据管理，不直接作为默认销售口径。

开发清单包含以下阶段：

1. 全量资料盘点、去重和版本识别。
2. 核心资料、条件资料、历史资料、测试资料和排除资料分层。
3. 首版核心资料选择及本地入库目录准备。
4. 产品、子产品、组件、版本和销售口语别名表。
5. 功能—产品映射及场景—产品组合映射。
6. 产品边界、适用条件、排除条件、必须追问和资料来源。
7. 100 条单轮模拟销售问题。
8. 100 组仅继承上一轮的上下文测试。
9. 产品专家审核表。
10. 包含题库、映射、上下文、统计和说明的 Excel 测试集。
11. 知识加载、检索排序、产品识别和回答框架接入。
12. 企业微信 20 轮真实问答验收。
13. 错题修复、回归测试、知识版本冻结和上线交接。

## 4. 验收标准

### 4.1 已完成成果包

- 压缩包可以正常解压。
- 只包含当前 Git 跟踪的安全成果。
- 不包含 `.env`、密钥、日志、依赖目录和原始公司资料。
- 包内代码、文档、知识文件、测试和正式 Excel 目录结构完整。

### 4.2 无涯开发清单

- 明确三条产品线及其边界。
- 每个阶段都有具体任务、交付物、检查方法和完成条件。
- 明确 100 条单轮题、100 组双轮题、20 轮企微验收和不低于 90% 的核心产品推荐正确率门槛。
- 明确所有产品口径在专家确认前仅用于内部实验。
- 明确原始公司资料与真实凭证不得上传 GitHub。
