# TDH 100 条模拟销售问题测试集设计

- 日期：2026-08-31
- 数据性质：人工合成测试数据
- 使用范围：TDH 产品匹配助手内部实验、离线评测和问题优化
- 审核状态：待产品专家确认

## 1. 目标与边界

基于现有 34 条“能力—产品映射”，构造 100 条不同表达方式和难度的模拟销售提问，用来测试助手能否：

1. 从销售语言中识别客户场景与所需能力。
2. 推荐正确的主推产品或产品组合。
3. 在存在合理替代方案时给出可选产品。
4. 在信息不足时先追问，而不是强行推荐。
5. 识别错误前提、越界问题和无法依据资料作出的承诺。

这 100 条问题不是销售真实原话，不能作为 `D1-08 收集 30 条真实销售需求` 的完成证据。正式验收前，仍需用真实销售问题替换或补充测试集。

## 2. 分类与数量

| 一级分类 | 数量 | 测试重点 |
| --- | ---: | --- |
| 产品版本与场景选型 | 22 | 数据湖、湖仓、湖仓集一体、集市、数据工程等版本选择 |
| 实时性、性能与时效 | 14 | 准实时、分钟级、秒级、亚秒级、高并发与混合负载 |
| 国产化迁移与替代 | 14 | CDH、Hadoop、MPP、Impala、Kudu、Hudi、Doris 等替代路径 |
| TDH、ArgoDB、TDC 产品边界 | 12 | 分析型、事务型、HTAP、多集群管理和数据服务边界 |
| 组件及多模型能力 | 16 | 搜索、宽表、流、时序、图、时空、消息和键值能力 |
| 老客户升级、EOS 与混部 | 8 | 历史版本升级、混部、停售版本和保留现有平台 |
| 信息不足、需要追问 | 8 | 缺少时效、负载、现有环境、部署或数据类型信息 |
| 错误前提、越界及安全问题 | 6 | 错误产品认知、价格承诺、绝对性能承诺和资料外结论 |
| **合计** | **100** |  |

## 3. 难度与表达方式

难度分布：

- 简单题 40 条：单一、明确场景，可以直接推荐。
- 中等题 40 条：包含两个以上条件，需要组合判断或给出可选方案。
- 困难题 20 条：信息缺失、条件冲突、错误前提或涉及越界承诺。

表达方式需混合使用短问句、客户场景转述、技术栈描述、预算或资源约束、性能目标、版本升级和带有错误前提的问法，避免只测试固定关键词。

## 4. 每条问题的字段

| 字段 | 用途 |
| --- | --- |
| 编号 | 唯一标识，格式为 `TDH-Q001` 至 `TDH-Q100` |
| 数据性质 | 固定为“模拟问题” |
| 一级分类 | 对应本设计第 2 节分类 |
| 二级场景 | 更具体的业务或技术场景 |
| 难度 | 简单、中等或困难 |
| 问题类型 | 选型、替代、对比、升级、追问、纠错或拒答 |
| 模拟销售提问 | 销售可能输入机器人的自然语言问题 |
| 已知条件 | 问题中明确给出的客户信息 |
| 缺失信息 | 影响推荐但尚未提供的信息；无则填写“无” |
| 预期动作 | 直接推荐、推荐并给可选方案、先追问再推荐、纠正错误前提或拒绝确定性承诺 |
| 预期主推产品 | 依据当前映射得到的首选产品；无法确定时填写“待补充信息”或“不应推荐” |
| 预期可选产品 | 有条件成立时可选的产品；无则填写“无” |
| 预期答案要点 | 机器人回答必须覆盖的核心结论与条件 |
| 必须追问 | 最多两个能够改变推荐结果的问题；无则填写“无” |
| 资料来源 | 对应现有能力映射的来源文件和定位信息 |
| 对应映射 | 对应 `TDH_CAPABILITY_PRODUCT_MAPPING.csv` 中的标准功能 |
| 产品专家 | 负责确认口径的人员，初始留空 |
| 审核状态 | 初始统一为“待产品专家确认” |
| 优化备注 | 用户后续修改问题或预期答案时填写 |

## 5. 交付形式

1. 仓库 CSV：`docs/knowledge/TDH_SYNTHETIC_TEST_QUESTIONS_100.csv`，作为自动化测试的可版本化数据源。
2. 可编辑 Excel：`TDH_100条模拟销售问题测试集.xlsx`，包含：
   - `100条模拟问题`：完整问题数据；
   - `分类统计`：分类、难度和预期动作数量；
   - `使用说明`：数据性质、审核方法和优化步骤。

## 6. 生成与验收规则

- 总行数必须为 100，编号不得重复或缺失。
- 分类数量和难度数量必须符合本设计。
- 每条普通选型题必须关联至少一条现有能力映射和可追溯来源。
- 信息不足题必须填写关键缺失信息和必须追问，不得直接给确定结论。
- 错误前提和越界题必须明确纠错或拒绝，不得虚构价格、性能、案例或产品能力。
- 主推产品、可选产品和推荐理由不得超出现有资料能够支持的范围。
- 所有问题初始审核状态均为“待产品专家确认”。
- Excel 与 CSV 中的 100 条主数据必须逐字段一致。
- 自动检查必须覆盖行数、编号、分类配额、难度配额、必填字段、枚举值和重复问题。

## 7. 后续优化方法

用户可以优先修改“模拟销售提问”和“优化备注”，保留编号、分类与预期结果作为对照。产品专家复核后，再修改主推产品、答案要点、资料来源和审核状态。真实销售原话应单独标记为“真实问题”，避免与模拟数据混淆。
