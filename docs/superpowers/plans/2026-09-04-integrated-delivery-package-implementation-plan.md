# 金融售前助手整合交付包实施计划

日期：2026-09-04

依据：`docs/superpowers/specs/2026-09-04-integrated-delivery-package-design.md`

## 实施步骤

1. 检查磁盘空间、源目录和目标名称，确保目标目录及 ZIP 不存在。
2. 新建交付包骨架，分别完整复制 TDH、LLMops 和无涯源目录。
3. 对源目录与副本统计文件数和普通文件字节数，逐文件比对 SHA-256。
4. 生成根目录交付总览和三个分类知识库说明 Markdown。
5. 生成交付索引、TDH、Ops、无涯四份新 Excel，不修改现有工作簿。
6. 检查四份 Excel 的关键区域、公式错误、工作表数量和视觉效果。
7. 生成交付包 SHA-256 清单和本地验收报告。
8. 从已校验目录生成 ZIP，并执行压缩包完整性检查。
9. 运行现有 Python、TypeScript 类型和功能回归测试。
10. 只将脱敏后的 Markdown、Excel、相对路径清单、脚本和测试提交 GitHub。

## 停止条件

- 目标路径已存在且无法使用全新名称。
- 剩余磁盘空间不足以同时保存完整副本与 ZIP。
- 任一分类复制后出现文件缺失、大小不一致或 SHA-256 不一致。
- 脱敏成果出现凭证、内网地址或个人绝对路径。

## 完成判定

完整目录副本、四份 Markdown、四份 Excel、SHA-256 清单和 ZIP 均存在并通过校验；现有源目录未发生变化；仓库自动测试通过；脱敏成果推送到 GitHub。
