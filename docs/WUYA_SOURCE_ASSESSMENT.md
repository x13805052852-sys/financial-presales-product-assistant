## 产品线和边界

| 产品或模块 | 主要职责 | 不应混用 |
| --- | --- | --- |
| TKH | 无涯知识平台，统筹问知、问数和知识门户 | 不是问知单产品的别名 |
| 无涯·问知 | 多源多模态知识、RAG 问答、写作和知识类助手 | 不承担结构化数据库的专业问数 |
| 无涯·问数 / Logits | 自然语言查询结构化数据、分析、可视化和多轮探索 | 不替代知识库和完整数据治理平台 |
| 知识门户 | 企业知识编目、检索、权限与共享 | 不等同于个人知识库或单次问答 |
| 问知深度研究助手 | 多源、多工具、可配置研究框架和报告 | 不等同于普通问答助手或问数产品 |
| 无涯问知AI工作站 | 面向小团队的一体化交付形态 | 不等同于 AIPC 个人版或普通服务器部署 |
| Co-Worker | 跨文件、系统和工具完成多步骤任务并交付结果 | 不等同于只回答问题的问知或问数 |
| XClaw | 历史或关联名称 | 与 Co-Worker 的正式关系未确认，不能静默合并 |

## 跨产品组合原则

- 企业知识问答：`TKH + 无涯·问知`。
- 治理增强智能问数：`TDS + 无涯·问数`。
- 知识问答进入业务流程：`Co-Worker + 无涯·问知`。
- 问数分析后生成报告、发送或催办：`Co-Worker + 无涯·问数`。
- 智能数据治理任务闭环：`Co-Worker + Astro + TDS`，底座按场景选择 TDH 或 ArgoDB。
- Co-Worker 多模型、算力和模型服务治理：`Co-Worker + Sophon LLMOps`，必要时比较 TDC AI 服务版。

## 必须由产品专家确认

1. 当前可正式销售的 TKH、问知、问数、AI 工作站和 Co-Worker 版本及 License。
2. `THK白皮书V3.0` 是否为 `TKH` 文件名错拼。
3. XClaw、OpenClaw 方案与 Co-Worker 的正式继承、改名或并行关系。
4. 问数功能清单 `2.X.0` 对应的准确版本和数据库适配范围。
5. 问知云端预置知识源、企业版、AIPC 版和 AI 工作站的功能差异。
6. Co-Worker 与 Astro、TDS、LLMOps、TDC AI 和 Agent Buddy 的正式组合与售卖边界。
7. 所有并发、吞吐、准确率、节省工时和性能数字的测试条件及可对客口径。
