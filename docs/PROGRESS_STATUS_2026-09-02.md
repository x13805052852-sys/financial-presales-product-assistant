## 已实现内容

1. 首版知识覆盖 TDH、ArgoDB、TDC、TDS、Astro，并保留产品来源、适用条件、排除条件和审核状态。
2. 支持三种自动回答框架：产品功能介绍、产品选型、风险追问。
3. 支持企业微信 API 模式机器人的长连接、消息接收、处理中提示、最终回复和断线重连。
4. 支持同一群聊内按提问人隔离的一轮上下文；上一轮最多保留 30 分钟，判断不清时按新问题处理。
5. 支持无依据拒答、冲突提示、模型超时与重试、答案产品依据校验、凭证脱敏日志。
6. 已建立 Git 提交门禁和 GitHub Actions，代码、知识表、设计文档和测试集均可通过 Git 版本回滚。

### D1-08 首版关闭说明

原计划要求收集 30 条真实销售需求。PO 于 2026-09-02 决定：鉴于现有测试表已覆盖 200 条单轮模拟销售问题和 100 组双轮场景，首版不再把“另行收集 30 条真实问题”作为阻断项，因此 D1-08 按首版完成。

这 300 组内容是基于产品资料构造的测试场景，**不是实际客户问答记录**。真实销售问题仍应在群测和灰度上线后进入错题清单，用于持续优化，但不再阻塞当前初版。
