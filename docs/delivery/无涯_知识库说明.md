## 产品边界

| 产品或模块 | 主要职责 |
| --- | --- |
| TKH | 无涯知识平台，统筹问知、问数和知识门户。 |
| 无涯·问知 | 多源多模态知识、RAG 问答、写作和知识助手。 |
| 无涯·问数 / Logits | 自然语言查询结构化数据、分析、可视化和多轮探索。 |
| 知识门户 | 企业知识编目、检索、权限和共享。 |
| 问知深度研究助手 | 组合多种来源和工具执行研究并生成报告。 |
| 无涯问知AI工作站 | 面向小团队的一体化交付形态。 |
| Co-Worker | 跨文件、系统和工具完成多步骤任务并交付结果。 |
| XClaw / OpenClaw | 历史或关联方案名称，与 Co-Worker 的正式关系待确认。 |

## 典型组合

- 企业知识问答：TKH + 无涯·问知。
- 治理增强智能问数：TDS + 无涯·问数。
- 知识问答进入业务流程：Co-Worker + 无涯·问知。
- 数据分析后生成报告、发送或催办：Co-Worker + 无涯·问数。
- 智能治理任务闭环：Co-Worker + Astro + TDS，底座按场景选择 TDH 或 ArgoDB。
- Co-Worker 多模型与算力治理：Co-Worker + Sophon LLMOps，必要时比较 TDC AI 服务版。

## 使用限制

- `THK白皮书V3.0` 的文件名疑似 TKH 错拼，必须由产品专家确认。
- 问数 `2.X.0` 不是精确版本，数据库适配范围需按目标版本确认。
- XClaw、OpenClaw 与 Co-Worker 的正式继承或并行关系不能自行判断。
- 并发、吞吐、准确率、节省工时和硬件配置不能脱离测试条件承诺。
- 当前映射仍待产品专家确认。

## 维护方式

使用功能映射、组合映射、单轮问题和双轮上下文题库共同维护。产品专家确认后填写正式口径；企业微信出现错题时，先修资料或映射，再运行全部回归测试。
