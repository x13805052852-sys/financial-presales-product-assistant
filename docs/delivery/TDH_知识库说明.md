## 产品边界

| 产品 | 主要职责 |
| --- | --- |
| TDH | 数据湖、湖仓集、批流处理、离线分析和统一数据底座，具体能力按 Edition 与版本确认。 |
| ArgoDB | 实时分析、HTAP、MPP 数据库替代等数据库场景。 |
| TDC | 数据平台、多集群统一管理和 AI 服务等平台能力，按产品版本区分。 |
| TDS | 数据接入、开发、治理、目录、质量和数据服务等专业工具。 |
| Astro | 通过自然语言和智能体生成建议、调用工具或编排任务，不替代专业治理工具和数据底座。 |

## 典型组合

- 实时写入、分析与治理：ArgoDB AP + TDS-SUITE-R + TDS-SUITE-D。
- 分钟级准实时入湖与治理：TDH 数据湖或湖仓集一体版 + TDS-SUITE-D。
- 智能治理辅助：数据底座 + TDS + Astro。
- 多集群统一管理：TDC 数据服务版 + 对应 TDH 集群。

## 使用限制

- 性能、并发、时延和兼容范围必须绑定版本、硬件、数据规模和测试条件。
- “实时”“亚秒级”“毫秒级”不能互相替代；资料没有明确证据时必须追问端到端口径。
- Astro 的智能体名称和数量存在资料版本差异，必须按目标版本确认。
- 当前映射仍待产品专家确认，只用于内部售前实验和测试。

## 维护方式

新增资料先进入资料清单，完成版本、重复、冲突和敏感性检查后再更新映射。问题测试必须保留预期产品、产品分工、资料来源和审核状态，修正后运行完整回归测试。
