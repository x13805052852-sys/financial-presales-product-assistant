## 产品域

| 产品域 | 主要职责 |
| --- | --- |
| Corpus Studio | 数据集、语料和知识加工相关能力。 |
| Model Foundry | 模型接入、训练、评测、发布和模型资产管理。 |
| Knowledge Lodge | 知识库、RAG 和知识工程能力。 |
| Agent Go | 智能体创建、编排、工具调用和应用交付。 |
| AI Infra | GPU、算力、推理服务、资源调度和运维管理。 |

## 组合边界

- 高质量企业 RAG：Knowledge Lodge + Corpus Studio，按数据底座补充 TDH。
- 智能体应用：Agent Go + Knowledge Lodge，模型服务和算力按需增加 Model Foundry 或 AI Infra。
- 业务数字员工：LLMOps 提供模型、知识、智能体和算力底座；具体业务入口或任务执行可与无涯、Co-Worker 配合。
- TDC AI 服务版与 LLMOps 在模型服务、算力和运营治理上可能重叠，必须按项目版本和售卖边界确认。

## 使用限制

- 旧材料中的 Agent Go 名称与当前资料可能不同，回答采用当前名称并提示版本差异。
- 规划能力、路线图、测试数字和竞品材料不能作为默认对客承诺。
- Token、并发、GPU 利用率和模型效果必须说明模型、硬件、数据集和测试方法。
- 当前映射仍待产品专家确认。

## 维护方式

使用功能映射和组合映射维护售前口径；产品专家审核表记录正式口径、审核人和日期。任何版本升级都要同步别名、资料来源、测试问题和边界说明。
