# 无涯企业微信 20 轮真实问答验收表

更新日期：2026-09-04

目标：在企业微信内部测试群验证无涯产品推荐、功能介绍、风险解释和单轮上下文能力。以下是内部测试脚本，不是产品专家确认后的正式对客口径。

## 判定标准

- 通过：核心产品或组合正确，分工清楚，没有越界承诺，资料来源可追溯。
- 部分通过：核心推荐正确，但遗漏必要追问、风险或产品分工。
- 不通过：核心推荐错误、错误继承上下文、编造功能或暴露敏感信息。
- 核心产品推荐正确率门槛：不低于 90%。

## 错题登记要求

每个“部分通过”或“不通过”的问题都要记录原问题、完整回答、预期产品、实际产品、命中知识编号、时间、发送人、问题类型和修复建议。修复后重新执行对应轮次及完整自动回归。
