# LLMOps 企业微信 20 轮真实问答验收表

更新日期：2026-09-03

目标：在企业微信内部测试群验证 LLMOps 产品推荐、功能介绍、风险解释和单轮上下文能力。以下内容是测试脚本，不是产品专家确认后的正式对客口径。

## 开测前检查

- [ ] 已在本机仓库根目录创建 `.env`，且仅使用轮换后的新密钥。
- [ ] `npm run smoke:model` 返回模型调用成功。
- [ ] `npm run start:wecom` 显示企业微信机器人连接成功。
- [ ] 测试群内仅有内部员工，不包含外部客户。
- [ ] 测试人知道每次需 `@机器人`，追问必须由同一人在 30 分钟内发送。
- [ ] 已指定记录人，异常答案保留完整问题、回答、时间和发送人。

## 判定标准

- **通过**：推荐产品或组合正确，产品分工清楚，未承诺证据外能力，资料来源可追溯。
- **部分通过**：核心推荐正确，但遗漏必要追问、风险或产品分工。
- **不通过**：核心产品推荐错误、继承了错误上下文、编造功能或暴露敏感信息。
- 核心产品推荐正确率门槛：不低于 90%，即 20 轮中至少 18 轮通过核心产品判定。

## 错题登记要求

每个“部分通过”或“不通过”的问题都必须记录：原问题、完整回答、预期产品、实际产品、命中的知识编号、发生时间、发送人、问题类型和修复建议。修复后必须重新执行本表对应轮次及完整自动化回归。

## 启动命令

在仓库根目录执行：

```bash
npm run smoke:model
npm run start:wecom
```

不要把 `.env`、API Key、Bot Secret 或运行日志提交到 GitHub。
