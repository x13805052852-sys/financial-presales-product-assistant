# 资料准备说明

## 1. 提供资料的顺序

1. 产品方案总表原始 Excel。
2. 首批产品的最新版产品介绍、方案书、FAQ 和培训材料。
3. 产品版本与能力差异说明。
4. 真实销售需求和产品专家确认的推荐答案。
5. 第二批产品资料和历史参考资料。

不需要一次性整理全部公司资料。首版只处理已经确定范围、能够确认版本和允许内部使用的内容。

## 2. 推荐目录结构

```text
资料包/
  00_产品总表/
  01_TDH/
  02_ArgoDB/
  03_TDC/
  04_TDS_Astro/
  05_LLMOps/
  06_TKH/
  07_无涯/
  08_Scope/
  90_历史资料_不入库/
  99_待确认/
```

## 3. 文件命名

推荐格式：

`产品名_资料类型_版本_发布日期_审核状态.ext`

示例：

`TDH_产品白皮书_9.3_2026-07-15_已确认.pdf`

## 4. 资料登记

每份文件在 `templates/source_manifest.csv` 中登记：

- 文件名称
- 产品线
- 资料类型
- 产品版本
- 发布日期
- 保密级别
- 审核状态
- 审核人
- 是否进入首版
- 备注

## 5. 能力与产品映射

在 `templates/capability_product_mapping.csv` 中记录：

- 客户原始需求
- 标准功能
- 解决方案
- 主推产品
- 可选产品
- 推荐理由
- 适用条件
- 排除条件
- 资料来源
- 确认人

没有资料来源或确认人的映射不得用于正式推荐。

## 6. 测试问题

在 `templates/acceptance_questions.csv` 中记录问题和预期结果。问题应尽量保留销售真实表达，不要全部改写成标准产品术语，否则无法验证助手是否真正理解客户需求。

## 7. 版本和冲突处理

- 已审批资料优先于未审批资料。
- 新版本优先于旧版本，但必须由产品专家确认能力是否发生变化。
- 产品总表与产品手册冲突时暂停该条推荐，由产品专家指定采用口径。
- 历史资料保留用于追溯，但不进入首版知识库。
